Globe Idea:

- On startup show the user a globe/wide area map (definitely 3D). The user can interact with the globe and spin the Earth. If the user zoom's close enough, national parks will begin to appear as little icons or bubbles of sorts. The user can hover over these bubbles (on pc) or click on them (on mobile) to learn more about the park. If they're on PC, clicking on the bubble switches tabs and we're shown info about the park (sightings, cameras, predictions, live community chat, analytics, etc.)

Ping Idea:

- Track user location
- User can drop a ping at their location to notify others of their sighting
- When users zoom out into the globe they can see these pings
